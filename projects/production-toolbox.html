Summary

The Game Development Production Toolbox is a resource I developed to support students entering production. Designed with beginners in mind, it provides clear, accessible explanations of essential production tools and workflows.

  • Created a structured, easy-to-use toolbox with nine essential production tools, each with a clear explanation, template, and demo.
  • Researched industry-standard production tools, gathering insights from experienced producers to ensure practical relevance.
  • Focused on accessibility, ensuring that each tool was simple to understand and adaptable to different teams.
  • Applied the toolbox in my own project and saw it successfully used in four additional student-led projects.
  • Strengthened my knowledge of production theory and real-world workflows by developing a resource used across multiple teams.
Producer work

Building the toolbox

01Research

As part of this project, I conducted research into the essential tools producers need to manage game development effectively. This involved gathering insights from industry veterans, exploring different programs, and evaluating which platforms were best suited for creating production templates.

Through this process, I not only gained a deeper understanding of production tools but also developed stronger research skills, learning how to find, analyse, and apply relevant information.

02Toolbox

The Production Toolbox I created consists of nine tools designed to streamline game production. Each tool includes a clear explanation of what it does, why it's useful, and how to use the accompanying template and demo. Developing this toolbox taught me a lot about making documents accessible and easy to use for a variety of teams.

Its impact goes beyond my own work. So far, it has been used in eight different projects. While I directly applied it to one project I produced, the other seven were led by different teams, proving its versatility and effectiveness in different development environments.

Takeaways

Developing the Game Development Production Toolbox showed me the importance of structure and accessibility in production workflows. By researching industry-standard tools and gathering insights from experienced producers, I developed my understanding of how to effectively manage game development.

This project also strengthened my ability to create clear and practical documentation. Making each tool in the toolbox easy to understand and use taught me how to break down complex concepts for different audiences. Seeing the toolbox used in multiple projects, even those in which I wasn't directly involved, proved its effectiveness and adaptability.

Beyond the technical aspects, this experience showed me the value of proactive problem-solving and continuous learning. Understanding production theory is one thing, but applying it in real-world scenarios solidifies knowledge. This project has prepared me to expand production processes in future teams.
